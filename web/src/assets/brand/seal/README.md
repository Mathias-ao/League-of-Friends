# AoF Seal

The AoF Seal is ceremonial, not decorative.

Use it only when the interface is marking league admission, turning a replay into the retained Battle record, showing the absence of a meaningful historical record, or marking a completed retained record.

## Variants

- `aof-seal-full.png`: primary hand-drawn rendition for large ceremonial use.
- `aof-seal-simple.png`: reduced hand-drawn rendition for medium states.
- `aof-seal-mark.svg`: reduced mark for small record/stamp use.
- SVG source renditions remain available where crisp vector rendering is more important than the drawn texture.

Do not use the seal as a generic navigation icon, button decoration, spinner, error icon, or card ornament.
