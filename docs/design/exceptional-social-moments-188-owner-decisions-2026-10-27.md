## The shared evidence-to-recognition firewall

1. One **league Battle = authoritative Match ID** (`battleId=matchId`) spanning all its Games. Original Game, replay actor, sourceEvent/operation ordinal and source-deed lineage remain. Two POVs, engagement episodes or two Games in one Match do **not** make two historical Battles. History uses #176 accepted Event/MatchPlan/Game ordering, not upload or completion time. Snapshot binds current authenticated READY source, roster and actor/opponent map, source revision/model, eligible competition, method coverage and relevant official result.
2. Expose modality separately: **OBSERVED_REQUEST**, **BOUNDED_INFERENCE** (Raid V3, Skirmish V2, Engagement V4, Pair Context/neutral measurements, #173), **RESULT_VERIFIED**, **EFFECT_VERIFIED** only with a genuine independent effect witness, **AUTHOR_ATTRIBUTED** for optional judgment, or **PENDING**. An inferred raid is not a kill; guard/build/queue is not an accomplished rescue or completed Castle; tribute is a request, not receipt. Low/unknown coverage never promotes to source-admitted.
3. Candidate key: `eventVersion + eventId/subtype + actor + directedCounterpartOrRecipient + currentBattleId + primaryIncidentLineage`, plus exact prior Battle and source witness refs. The **Chronicle scene ID remains the existing stable pair×Battle identity**; event categories are attributes of a recomputable scene, not a second page/score pipeline.
4. **One deed, many honest surfaces:** a Game statistic can show in Battle 4-card strip, selected Event 4–5 roundoff, Season Record Book / personal PB, owner-approved tier Achievement, ordinary social claim, and Chronicle narration only if **each independent predicate qualifies**. The event label produces **zero extra ordinary contributions**, zero stage jumps and zero Trophy/Distinction entitlement. One incident with overlapping Raid/Skirmish/Assist facets retains one underlying canonical deed. Pick **one featured exceptional headline per actor×pair×Battle/turning point** (Treachery, if qualified, has highest priority); other qualified cross-family facts stay marginal context.
5. Missing essential witness = `PENDING_EVIDENCE`; an actual failed gate = `NOT_QUALIFIED`; proposed rule/threshold = `UNCONFIGURED_POLICY`. "No observation" is not "no act." No inferred automatic reverse Relationship action. Stage 3+ ordinary pair progression still requires independently qualified corresponding opposite-direction conduct; strict Treachery alone has the existing special victim→responsible Hostility path after king-loss and binding victim judgment.
6. **Correction:** replace/withdraw current source, active Game result, opponent/controller binding, valid historical ordering, episode identity or prior chapter → invalidate/recompute affected event and dependent private Chronicle prose **at the original historical position**; keep stable scene/seen-history identity, preserve audit, remove/reclassify unsupported headline; surviving ordinary facts may remain. A separately awarded permanent Distinction survives *being surpassed*, not **proof revocation**.
