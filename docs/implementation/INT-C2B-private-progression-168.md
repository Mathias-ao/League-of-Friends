## Corrections, incomplete input and privacy

No simulated projection is written. A new read always recomputes #139 from only
current admitted originals. Withdrawal, supersession, result revision, remapping,
plan revision or access change therefore cannot leave durable stale credits.
Any missing current source masks current stages as Pending; exposed banks and
transitions are explicitly only the verified subset. Unknown canonical order
blocks dependent historical projections using the existing evaluator.
Source-event provenance and original operation order never become League order.
Chronicle handoff `AOF_SOCIAL_PRIVATE_CHRONICLE_SEAM_1` carries source/schedule/input
revisions with `invitationAuthority=false, judgmentAuthority=false`. Ordinary
inferred gameplay cannot manufacture rare invitations, judgments or reverse
credits. Reverse player Claims, private notes, replay names, raw payloads, storage
paths and auth UIDs are not returned. No logs/artifacts contain replay payloads.
