## Bounds and privacy

Personality collector: up to **256 league Match documents**, **64 own Game documents**, Match ID pages of **64**, **512 KiB** complete response, **100-second** elapsed guard inside a 120-second callable. Hard limits are technical I/O/response bounds, not scoring/sample defaults. No silent truncated history or complete-looking prefix: exceeding any bound fails with `resource-exhausted`. Sequential artifact reads keep peak memory bounded; the elapsed guard does not cancel a stalled SDK RPC and does not establish a cloud latency SLA.

Chronicle retains #136's separately documented **256 Matches / 768 Games / 100-second** complete-or-error envelope. These are distinct read models and individually fenced snapshots, not an atomically persisted combined social projection. Private Personality does not consume legacy shadow stages. Accepted #139 remains the sole future six-track evaluator once independently accepted source Claims and approved rules exist.

Both existing backend `AOF_INT_V1_PRIVATE_READS=source-v1` and new `AOF_INT_V1_PRIVATE_HISTORY=battle-v1` are required. Client Personality/private-book routing requires `VITE_AOF_INT_V1_PRIVATE_HISTORY=battle-v1`. Defaults remain OFF; backend and UI reject production even with the opt-in value. Local demo process opt-ins are tests only; no live flag/config changes are authorized.
